# Дорожная канцелярия

Расширение для SillyTavern: кожаная папка вместо телефона. Персонаж узнаёт новости
так, как это делал бы средневековый человек — читает газету, смотрит доску объявлений
и считает монеты.

## Установка

Ставится через вкладку **Расширения** в SillyTavern:

1. Настройки → **Расширения** (иконка плагина в верхней панели)
2. **Установить из репозитория** → вставить адрес этого репозитория
3. Обновить список, выбрать «Дорожная канцелярия», нажать **Установить**

Либо вручную: скопировать папку в `public/scripts/extensions/third-party/`
и перезапустить SillyTavern.

**Посмотреть без SillyTavern:** открыть `preview/index.html` двойным кликом.
Витрина с заготовленными данными — показывает весь интерфейс, но ничего
не генерирует и никуда не пишет.

## Четыре вкладки

### Газета

Слухи и официальные документы в одном выпуске. Ключевая идея — **две независимые
оси**:

| | правда | охват |
|---|---|---|
| Слух | низкая, угасает со временем | высокий, распространяется |
| Указ | высокая, не угасает | низкий, его прочитали и забыли |

Достоверность и популярность — разные вещи. Слух в 80% охвата и 20% правды —
обычное дело; указ в 95% правды и 10% охвата — тоже. Реакции толпы двигают оси
независимо: сомнение бьёт по правде и не трогает охват, пересказ наоборот.

```
правда = база − (угасание × сутки) + подтверждения − сомнения
охват  = база − (забывание × сутки) + пересказы
```

Типы: 📯 глашатай, 🎭 сплетни знати, 🛒 рыночная болтовня, 🍺 таверные байки,
🗣️ уличный шёпот | 👑 указ, 📜 манифест, 🧾 сбор, ⛪ проповедь.

Реакции: 🙌 подтверждают **+2% правды**, 🤔 сомневаются **−3% правды**,
🗣️ пересказывают **+4% охвата**. Кнопка «опровергнуть» обнуляет правду.
Официальные документы опровергнуть нельзя.

### Доска объявлений

Объявления на заборе: работа, спутники, товар, случайные находки. У каждого —
автор, место и награда. Модель читает лорбук, карточку и историю чата, поэтому
объявления соответствуют миру. Объявление можно взять или сорвать.

### Кошель

Валюту **придумывает модель**, а не расширение. Жёстко прописанные «золотые
и серебряные» насиловали бы любой мир, поэтому номиналы генерируются из контекста
ролевой: в Виченце это будут флорины, в северных землях — что-то другое.
До генерации кошель пустой — никаких монет из воздуха.

### Сбор

Выбор модели для генерации, город, галочки, очистка папки ролевой.

## Отдельная модель и ключи

Содержимое канцелярии можно генерировать другой моделью, чтобы не нагружать
ту, что пишет роль.

**Расширение не хранит ключи. Вообще.** Оно хранит одну строку — *имя* профиля
из штатного Connection Manager:

```
travelersFolio_settings.generationProfile = "Дешёвая быстрая"
```

Ни URL, ни заголовков, ни ключей. Профиль ссылается на секрет через `secret-id`,
а ключи лежат в `secrets.json` на сервере SillyTavern и в браузер не попадают.

Перед тихим запросом расширение подставляет настройки профиля через
`executeSlashCommands`, а после возвращает прежние — модель чата не затрагивается.
Нет профиля или профиль удалён → генерация идёт через текущую модель.

## Ключевые решения

**Ленивая генерация.** Всё по кнопке: «Свежий выпуск», «Что на доске»,
«Какая здесь валюта». Автоматики нет — каждая такая генерация писала бы в чат
и раздувала историю.

**Батч.** Один запрос возвращает и слухи, и документы, и несколько объявлений.
Никогда N запросов.

**Реакции не пишутся в чат.** Они лежат в metadata и считаются локально. Каждый
лайк как скрытое сообщение — проблема, которую расширение сознательно обходит.

**Фоновые триггеры выключены** (`ambientTriggers: false`). Если включить,
срабатывают при словах «рынок», «таверна», «дворец» в реплике персонажа.

**В промпт уходит срез** — пять свежих записей, не вся коллекция.

## Настройки

```js
travelersFolio.saveSettings({ city: 'Новгород', generationProfile: 'Дешёвая быстрая' });
```

| Ключ | По умолчанию | Что делает |
|------|--------------|------------|
| `city` | `''` | Подставляется в промпты |
| `generationProfile` | `''` | Имя профиля Connection Manager |
| `ambientTriggers` | `false` | Фоновые слухи по локациям |
| `maxItems` | `48` | Сколько записей в газете хранить |
| `maxPerRefresh` | `6` | Сколько за один выпуск |
| `injectPrompt` | `true` | Инструкции для модели |

## Проверка

```bash
node test/logic.test.mjs
```

33 проверки: обе оси газеты (угасание, независимость реакций, потолки, метки),
парсер выпуска (мусор и неизвестные типы отбрасываются), генерация валюты
(порядок номиналов, дубликаты) и арифметика кошелька.

## Планируется

- Торговцы: товар находит персонажа, а не наоборот
- Гонцы с поручениями вместо SMS
- Гильдии (замена Discord)
- Карты и вести
